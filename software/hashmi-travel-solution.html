Technical Specs

System Requirements

Designed to run smoothly on standard office hardware. No high-end specs required.

Minimum Requirements
  • OS: Windows 10 (64-bit) or Windows 11
  • Processor: Intel Core i3 or equivalent AMD (1.5 GHz+)
  • RAM: 4 GB minimum
  • Storage: 500 MB free disk space
  • Display: 1024×768 resolution
  • Internet: Required only for initial activation
Recommended for Best Performance
  • OS: Windows 11 (64-bit)
  • Processor: Intel Core i5 or AMD Ryzen 5 (2.0 GHz+)
  • RAM: 8 GB
  • Storage: 2 GB free (SSD preferred for faster backups)
  • Display: 1920×1080 Full HD
  • Printer: Any Windows-compatible printer for invoices
Mac / Linux: Not natively supported in v1.0. A macOS-compatible version is planned for a future release. Please contact us if you need Mac support — we can add you to the early-access list.
