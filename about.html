⚙️ How HashmiTools Works — Technical Transparency

All HashmiTools tools run entirely client-side using modern JavaScript APIs. Here is the technology behind the most popular tools:

  • PDF Editor & Merge: Uses PDF.js (Mozilla) for rendering and pdf-lib for editing. Canvas annotations powered by Fabric.js.
  • Image Tools: Uses the HTML5 Canvas API for compression, cropping, resizing, and filter application. No third-party image processing server.
  • QR Code Generator: Uses qrcode.js — all QR generation is local.
  • Finance Calculators: Pure JavaScript arithmetic — no server calls, instant results.
  • PDF Compression: Optimizes PDF image streams and removes redundant data using pdf-lib, entirely in browser.

This architecture means HashmiTools works even without internet after initial page load, and is as fast as your device can process — no server latency.

👤 The Story Behind HashmiTools

HashmiTools was founded by Hassan Hashmi, a software developer based in Karachi, Pakistan. The idea came from a deeply practical frustration: every time Hassan needed to compress a PDF to email a form, convert an image, or calculate a loan EMI, every "free" tool online either demanded an account, put a watermark on the output, charged after 3 uses, or—worst of all—uploaded files to a server somewhere without being transparent about it.

As a developer, Hassan knew these tools could be built to run entirely inside the browser, with zero server uploads. In late 2024, he started building HashmiTools as a side project during evenings after work. The first version had five tools. Within three months, the site had grown to 50+ tools — driven almost entirely by user requests from people who found the site through Google and shared it with friends.

The Pakistani-specific tools (Zakat calculator, inheritance calculator, prayer times, Pakistan income tax) were added after Hassan noticed that many finance calculators online either ignored Pakistani Rupee or used outdated tax slabs. The Islamic tools were built in consultation with users from the Pakistani and diaspora Muslim community who asked for calculators that followed Hanafi fiqh correctly.

What Hassan believes in: Productivity tools should not be paywalled. A student in Lahore should have access to the same quality PDF editing, image compression, and financial calculation tools as someone paying for Adobe Acrobat in New York. HashmiTools will remain free, always.
