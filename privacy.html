🔒 Privacy Policy

Your Privacy is Our Priority

HashmiTools is built on a simple principle: your files and data belong to you. We never see them, never store them, never share them.

Last updated: July 2, 2025

👤No Personal Data CollectedWe do not collect your name, email, phone number, or any identifying information. Ever.

📂 1. File Processing — Client-Side Only

This is the most important part of our privacy policy. Every file you upload to any HashmiTools tool is processed entirely within your web browser using JavaScript. This applies to:

  • PDF files edited, merged, compressed, or converted using HashmiTools PDF tools
  • Images compressed, edited, cropped, or converted using HashmiTools Image tools
  • Any document, photo, or file used with any HashmiTools tool
Technical confirmation: HashmiTools has no server infrastructure for file processing. Our tools use browser-native APIs (HTML5 Canvas, Web Workers) and client-side JavaScript libraries (PDF.js, pdf-lib, Fabric.js). There is no upload endpoint on our servers because none is needed.

Once you close your browser tab, all file data is cleared from browser memory. We have no access to your files at any point.

📊 2. What Data We Collect (and Don't)

We do NOT collect:

  • Personal information (name, email, phone, address)
  • File contents, filenames, or file metadata
  • Payment information (tools are free, no payments)
  • Account credentials (no accounts exist)
  • Precise location data
  • Search history or tool usage per individual user

We may collect (anonymous, aggregated only):

  • Page view counts per tool (to understand which tools are most useful)
  • Country-level geographic data (to understand our audience)
  • Browser type and device type (to improve compatibility)
  • Referral source (to understand how users find HashmiTools)

All analytics data is aggregated and anonymized — it cannot be linked to any individual user.

🍪 3. Cookies and Local Storage

HashmiTools uses browser localStorage only for saving your preferences:

  • Theme preference (light/dark mode) — stored locally, never transmitted
  • Auto-save data in the PDF Editor — stored locally for session recovery, deleted after 2 hours
  • Calculator inputs — some tools save last-used values locally for convenience

We do not use advertising cookies, third-party tracking cookies, or any cookies that track you across websites.

You can clear all HashmiTools localStorage data at any time by clearing your browser's site data for hashmitools.com.

🔗 5. Third-Party Services

HashmiTools uses a small number of third-party services solely for delivering the website:

👶 6. Children's Privacy

HashmiTools does not knowingly collect any personal information from children under 13. Since we collect no personal information from any user, children can safely use HashmiTools tools (PDF converters, calculators, image tools) without any privacy concerns.
