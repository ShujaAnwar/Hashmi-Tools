Frequently Asked Questions

Why do I need a Hugging Face API key?
Our AI tools connect directly to the Hugging Face Inference API from your browser. The API key is needed for authentication. You can get a completely free API key at huggingface.co by creating a free account and generating an Access Token. Your key is stored locally in your browser — never on our servers.
Which AI model powers these tools?
We use Mistral-7B-Instruct-v0.2, an open-source instruction-following language model developed by Mistral AI. It excels at content generation, summarization, code explanation, and creative writing tasks while being fast and efficient.
Is my content/data private?
Your prompts are sent to the Hugging Face Inference API and processed by Mistral-7B. Hugging Face's privacy policy applies to this processing. We do not store, log, or have access to any content you generate. Your API key is stored only in your local browser storage.
What happens when the AI model is loading?
Hugging Face free-tier models may need to "warm up" if they haven't been used recently. This can take 20-30 seconds on first use. The tool will show a "Model Loading" status and retry automatically. Subsequent requests are much faster.
