How it works: Images are loaded into an HTML5 Canvas element at your chosen quality setting. The Canvas exports the result as a compressed JPEG/PNG/WebP data URL. All processing happens entirely in your browser — no file is uploaded to any server.

Tips: JPEG quality 70-85% gives excellent visual quality with significant size reduction. WebP typically achieves 25-35% smaller files than JPEG at the same quality. PNG compression reduces file size without quality loss (lossless).
