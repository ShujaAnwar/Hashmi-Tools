Frequently Asked Questions

Are my PDF files safe?
Absolutely. All processing is done entirely in your browser using JavaScript libraries (pdf-lib.js and jsPDF). Your files are never uploaded to any server, never stored anywhere, and never accessible by anyone. Everything stays on your device.
What is the maximum file size I can process?
Since processing happens in your browser, the limit depends on your device's RAM. Generally, files up to 50MB work well on most devices. Very large files (100MB+) may be slow on older devices. For best results, we recommend files under 30MB.
How much can PDF Compress reduce file size?
Compression results vary based on content. PDFs with many images can often be reduced by 50-80%. Text-heavy PDFs with fewer images may see 10-30% reduction. Our tool uses Canvas API JPEG resampling which is most effective on image-heavy documents.
Can I merge password-protected PDFs?
Currently our tools work best with unprotected PDFs. Password-protected PDFs require decryption which is not supported in the current version. Please remove the password protection first using your PDF reader, then use our tools.
